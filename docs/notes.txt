from fruit import Fruta

    (5, 5) # CABEÇA (primeira posição)
    )
fruta = Fruta(
    (8, 6)
    )

cobra.mover(direcao)


if cabeca == fruta.posicao:
    cobra.comer(fruta)

Já o __init__ é diferente.

Ele não existe para executar uma ação.

Ele existe para responder:

"Como esse objeto nasce?"

Por isso eu gosto da analogia:

cobra = Snake((5, 5))

O Python pergunta:

"Ok, vou criar uma cobra."

"Quais informações ela precisa ter ao nascer?"

E aí o __init__ responde:

posição
pontuação
estado de crescimento
